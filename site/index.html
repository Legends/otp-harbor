Private TOTP authenticator

Generate 2FA codes locally, without a cloud account.

OTP Harbor is an open-source authenticator application for time-based one-time passwords (TOTP). TOTP is the standard commonly used by websites and services when they ask you to scan a QR code while enabling two-factor authentication or multi-factor authentication.

Instead of storing your authentication secrets in an OTP Harbor cloud service, the application keeps them locally in an encrypted vault. TOTP codes are generated on your device from the stored secret.

OTP Harbor supports standard otpauth:// QR codes as well as Google Authenticator transfer QR codes for bulk migration.

Encrypted local vault

TOTP seeds are protected locally using AES-256-GCM encryption with a key derived from your master password using Argon2id.

Offline TOTP generation

Generate your two-factor authentication codes locally without requiring an OTP Harbor cloud account or cloud-based vault.

QR code import

Add authenticator accounts by scanning standard TOTP QR codes instead of manually entering long Base32 secrets.

Google Authenticator import

Import accounts from Google Authenticator transfer QR code images, including multi-part exports containing multiple authenticator accounts.

Quick unlock

Use platform-specific quick unlock while retaining the master password as the portable recovery path for your encrypted vault.

Encrypted backup & restore

Create portable encrypted backups and restore them on supported OTP Harbor platforms instead of depending exclusively on a single device.

Fast account actions

Right-click an existing desktop account to edit it, show its QR code or delete it after confirmation.

Authenticator migration

Import accounts from Google Authenticator.

OTP Harbor recognizes both normal otpauth:// TOTP QR codes and Google Authenticator migration QR codes.

To migrate multiple accounts, start the account export in Google Authenticator, save a crisp screenshot of each generated transfer QR code, then choose each image under Settings > Import / Export. Importing the original pixels avoids unreliable desktop-camera focus and resolution. Multi-part exports are selected in sequence.

Migration QR codes contain authentication secrets and must therefore be treated as sensitive information. After migration, verify several generated codes and create a fresh encrypted backup.

Frequently asked questions

OTP Harbor authenticator FAQ

What is OTP Harbor?

OTP Harbor is an open-source TOTP and two-factor authentication application that stores authenticator secrets in an encrypted local vault and generates one-time passwords on your device.

Does OTP Harbor work offline?

Core TOTP generation and access to the local encrypted vault do not require an OTP Harbor cloud account. Authentication codes are generated locally.

Can OTP Harbor import Google Authenticator accounts?

Yes. OTP Harbor supports normal TOTP QR codes and saved Google Authenticator transfer QR code images used for bulk account migration.

How are TOTP secrets protected?

OTP Harbor stores OTP seeds in an AES-256-GCM encrypted local vault and derives the vault key from the master password using Argon2id.

Which TOTP algorithm does OTP Harbor use?

OTP Harbor currently uses the common TOTP profile: SHA-1, six-digit codes and a 30-second period, following the widely used TOTP standard defined by RFC 6238.

Is OTP Harbor open source?

Yes. OTP Harbor is published on GitHub under the MIT license, allowing its implementation and security-related code to be independently inspected.

Which operating systems does OTP Harbor support?

The desktop project targets Windows, macOS and Linux. An Android 9+ development preview is also under active development.

Can OTP Harbor back up authenticator accounts?

Yes. OTP Harbor supports encrypted backup and restore so the vault can be recovered or transferred between supported platforms.
