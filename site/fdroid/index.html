Get OTP Harbor with F-Droid

Add the OTP Harbor repository to your F-Droid client, then install the app and receive updates there. This additional repository is maintained by OTP Harbor and is separate from the official F-Droid catalog.

Add repository to F-DroidGet the F-Droid client

Already installed from GitHub? These are the same production-signed APKs. Compatible updates keep your local vault in place.

Add it manually

  1. Open F-Droid, go to Settings, then Repositories, and choose to add a repository.
  2. Paste the repository address below and confirm the certificate fingerprint.
  3. Refresh repositories, search for OTP Harbor, and install it.

Your data stays local

F-Droid downloads and updates the app. Your accounts, passwords and encrypted vault are not uploaded to this repository.

Keep an encrypted backup

Before changing an app’s installation source, export an encrypted backup and keep its password safe. If Android reports a conflicting signature, keep the existing installation and your data until you have verified the backup. Development builds and a future official F-Droid package may use different signatures.
